# NIGHT CIRCUIT: Neon Streets

Gioco di guida arcade 3D per browser desktop.

Gioca: https://giovannifantini.github.io/night-circuit/

WASD: guida. C: visuale. H: garage. G: mappa. Esc: pausa.

Questo repository contiene il gioco compilato e gli asset generati per il progetto. Texture, modelli, font, icone, effetti sonori e musica sono originali e generati dal codice del progetto. Le licenze delle librerie runtime sono nella cartella licenses.

I progressi vengono salvati nel browser. Per trasferirli da un altro indirizzo o PC usare Esporta e Importa salvataggio nel gioco.
